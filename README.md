# Everbloom Pty Ltd

A responsive website for Everbloom's beauty services and technology offerings.

## Services

- Hair braiding, eyelash extensions, hair installation, and nail services
- Web development
- Digital skills training for high school learners

## Run locally

Open `index.html` in a web browser. The site uses plain HTML, CSS, and JavaScript; no build step is required.

## Before publishing

Replace the example contact address `hello@everbloom.com` in `index.html` with Everbloom's business email address.

## Project files

- `index.html` — page content and structure
- `styles.css` — responsive styles
- `script.js` — mobile navigation and current-year footer
